# Parking Space Management System

A WordPress-based parking space management system with booking, check-in/out functionality, and user profiles.

## Project Overview

This system provides a comprehensive solution for managing parking spaces with features including:

- User registration and authentication
- Parking space booking system
- Check-in and check-out functionality
- Driver job management
- Customer profiles
- Payment processing
- Dashboard for monitoring

## Key Features

- **Booking System**: Users can book parking spaces through an intuitive interface
- **Check-in/Check-out**: Manage vehicle entry and exit from parking areas
- **User Management**: Registration, login, and profile management
- **Driver Services**: Create and manage driver jobs
- **Payment Integration**: Complete payment processing workflow
- **Admin Dashboard**: Comprehensive monitoring and control panel

## Technology Stack

- WordPress CMS
- PHP
- JavaScript
- CSS
- MySQL Database

## Installation

1. Clone the repository
2. Set up a WordPress environment
3. Import the `acf-export.json` file for custom fields
4. Configure the database connection in `wp-config.php`
5. Activate the theme

## File Structure

- `booking/` - Booking related functionality
- `control/` - Administrative control panels
- `dashboard/` - Dashboard components
- `customize/` - Theme customization files
- Core PHP pages for various functionalities (checkin.php, checkout.php, etc.)

## Usage

After installation, users can:

1. Register for an account
2. Browse available parking spaces
3. Book parking slots
4. Check in and out of parking areas
5. Manage their profile and payment information

Administrators can:

1. Monitor all bookings
2. Manage parking spaces
3. Oversee check-in/check-out activities
4. Create driver jobs
5. View reports and analytics
